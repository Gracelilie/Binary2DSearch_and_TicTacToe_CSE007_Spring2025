# Binary 2D Search and Tic Tac Toe — CSE007 Homeworks 5 and 6

Author: Grace-lilie Acheampong  
Course: CSE007 Spring 2025  
Language: Java 11

## Description
This combined repository contains two small Java projects.

1. Homework 5  
   File: Binary2DSearch.java  
   Implements an efficient search for a target inside a sorted 2D matrix using binary search reasoning along rows and columns. Practices nested loops, conditional logic, and divide and conquer thinking.

2. Homework 6  
   Files: Board.java and Game.java  
   A console Tic Tac Toe. Board models the grid, moves, and win checks. Game manages turns, input, and outcome reporting. Practices classes, object design, and separation of concerns.

## Real world application
Binary 2D Search  
Used in fast lookup over structured tables such as database indexes, geographic grids, and spreadsheet like datasets where quick find is important.

Tic Tac Toe with Board and Game  
Mirrors how interactive systems separate model from controller. The pattern scales to games, user interfaces, and any app that manages state, rules, and user interaction.
